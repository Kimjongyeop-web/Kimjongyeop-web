# 개발 과정

## 1. 초기 구조

실시간 시세와 가상매매를 분리하고, 종목 후보 탐색·분봉 생성·가상 포지션 저장·알림 전송을 구현했습니다. 실제 주문 기능은 포함하지 않았습니다.

## 2. 데이터 공급 경로 통합

초기 후보 순위와 과거 거래량에 사용하던 pykrx를 제거했습니다. 일봉 거래량은 한투 API로 전환했습니다. 시총 순위 API를 연속 조회하는 접근은 실제 응답이 30종목에 그쳐 요구 순위를 확보하지 못했습니다. 불완전한 순위로 진행하지 않도록 중단한 뒤, 공개 전체 종목정보 파일로 후보를 선정하는 방식으로 교체했습니다. 순위가 파일 기준이라는 의미 변화도 명시했습니다.

## 3. 분봉 검증 및 진단

데이터 부족과 추세 조건 미충족이 같은 문구로 출력되는 문제를 분리했습니다. 완성된 고유 1분봉 3개만 집계하고, 중복·무효 행과 미완성 구간을 제외합니다. 집계 OHLCV를 별도 계산과 대조하고, 시간 연산 라이브러리 경고의 원인도 수정했습니다.

## 4. 실행 상태 가독성

종목별 반복 상세 출력은 상세 모드로 옮겼습니다. 기본 화면은 준비 진행, 최근 수신 상태, 포지션·실현손익, 분봉 부족/추세 탈락/통과 수를 표시합니다. 중요한 오류와 거래 이벤트는 유지합니다.

## 5. 진입 조건 조정

여러 조건의 동시 충족이 드문 현상을 확인하고 돌파 기준을 20개에서 10개 분봉으로 줄였습니다. 거래량 증가율과 양봉 몸통 기준을 완화하고 고가 근접도 조건 및 시장 대용 점수에 따른 추가 가중을 제거했습니다. 3분봉 추세, 최소 거래량, 보유 한도, 손절·익절은 유지했습니다.

한정된 과거 표본에서 신호 빈도가 늘어나는지 확인했지만 최적화된 전략이나 수익성 개선으로 해석하지 않습니다. 여러 거래일 및 비용 포함 검증이 후속 과제입니다.

## 공개 범위

개인정보, 실제 인증정보, 개인 실행 로그, 거래내역, 저장 분봉, 로컬 경로, 원본 데이터는 포함하지 않습니다. 재현 가능한 합성 데이터 테스트와 구현 내용을 공개합니다.
